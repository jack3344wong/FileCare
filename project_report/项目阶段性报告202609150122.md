## 一、项目概述

**文件管家 / FileCare** 是一款面向体制内非技术用户的 Windows 文件管理桌面工具，基于 **Python + PyQt5 + SQLite** 开发。Win7 发布构建固定使用 64 位 Python 3.8.10。

### 核心功能（已完成）

| 功能模块 | 说明 | 状态 |
|----------|------|------|
| 🧹 大文件清理 | 扫描大文件/文件夹，提供清理建议 | ✅ 已完成 |
| 📊 空间可视化 | Treemap 风格展示目录占用，支持逐级下钻 | ✅ 已完成 |
| 🔍 文件名搜索 | 完整索引磁盘目录，支持通配符和格式过滤 | ✅ 已完成 |
| 📄 内容搜索 | 本地检索 PDF/Word/Excel/PPT/RTF/文本 | ✅ 已完成 |
| 🗑️ 回收站管理 | 查看、恢复或永久删除回收站项目 | ✅ 已完成 |
| 📦 安装包 | Inno Setup 单文件安装包，含安装动画和首批索引 | ✅ 已完成 |
| ⚙️ 设置页面 | 集中管理软件配置，支持深色主题 | ✅ 已完成 |

### 2.4 后台运行与系统托盘 ⏳ **待开发**

**目标：** 用户关闭窗口后软件不退出，在系统托盘保持运行。

**核心行为：**

| 操作 | 行为 |
|------|------|
| 点击关闭按钮（X） | 默认最小化到托盘（可在设置中选择"直接退出"） |
| Shift + 关闭按钮 | 强制退出（快捷操作） |
| 托盘左键单击 | 恢复/最小化主窗口 |
| 托盘右键单击 | 弹出菜单（打开/扫描/设置/检查更新/退出） |

**技术要求：**
- 使用 PyQt5 的 `QSystemTrayIcon`
- 重写 `closeEvent` 拦截关闭事件
- 后台运行时 CPU < 5%，内存稳定无泄漏

### 2.5 开机自启动 ⏳ **待开发**

**目标：** 用户可选择让软件在系统启动时自动运行。

**实现方案：**
- 写入注册表 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`
- 使用当前用户权限（HKCU），不需要管理员权限，不弹 UAC
- 支持命令行参数 `--minimized` 控制启动后直接最小化到托盘
- 卸载时自动清理注册表项
